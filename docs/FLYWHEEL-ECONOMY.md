## 0. ФИЛОСОФИЯ

Это не приложение. Это игра, в которую люди играют, не зная что они играют.
Каждый элемент — коллекционирование, аукционы, подписки, стримы, реклама, банкноты — это геймифицированный интерфейс к математическому двигателю внутреннего сгорания.

Движок должен работать так:
  - Человек заходит поиграть → остаётся ради денег
  - Человек заходит ради денег → остаётся играть
  - Ты не можешь перестать, потому что остановка = потеря накопленного

## 2. ДВИЖОК: МАТЕМАТИЧЕСКИЙ ЦИКЛ САМОГЕНЕРАЦИИ

### 2.1 Главный цикл (The Silver Flywheel)

```
  ┌──────────────────────────────────────────────────────────┐
  │                                                          │
  │  1. Люди покупают банкноты, подписки, бустеры           │
  │     (пополнение казначейства в USDT/USDC/крипта)         │
  │                     ↓                                    │
  │  2. Казначейство накапливает USDT                        │
  │                     ↓                                    │
  │  3. При достижении порога (напр. $1,000 USDT):           │
  │     → Автоматический триггер SILVER ROUND                 │
  │     → Покупаем физическое серебро у брокера              │
  │     → 20% → в резерв Острова                             │
  │     → 80% → токенизируется в ng (монетизация)            │
  │                     ↓                                    │
  │  4. 80% пула → pro-rata дивиденды держателям банкнот     │
  │     → владельцы Rare получают больше (множитель x2-x5)    │
  │     → владельцы Golden Royal получают x4                 │
  │                     ↓                                    │
  │  5. Дивиденды = доход банкнотхолдера                     │
  │     → Стимул покупать ещё банкноты                       │
  │     → Стимул апгрейдить редкость (Common → Rare → Epic)  │
  │     → Стимул искать Golden Royal статус                  │
  │                     ↓                                    │
  │  6. Новые покупатели → больше USDT → шаг 1               │
  │                                                          │
  └──────────────────────────────────────────────────────────┘
```

### 2.3 Автоматическая эмиссия новых колод (Auto-mint)

Когда казначейство достигает определённых уровней, система **сама минтит новые колоды банкнот** и выставляет их на продажу:

```go
type AutoMintEngine struct {
    tiers []AutoMintTier
}

type AutoMintTier struct {
    TreasuryThresholdNg int64  // при каком размере казны
    DeckSize            int    // сколько банкнот в колоде
    RarityDistribution  map[string]float64 // common: 0.6, rare: 0.25, epic: 0.1, legendary: 0.05
    PricePerBanknoteNg  int64  // цена продажи
}
```

Пример:

| Tier | Казна (ng) | Колода | Редкость | Цена за банкноту |
|------|-----------|--------|----------|-----------------|
| T1 | 10,000,000,000,000 | 100 шт | 60%C 25%R 10%E 5%L | 500,000,000 ng |
| T2 | 50,000,000,000,000 | 250 шт | 50%C 30%R 12%E 7%L 1%G | 750,000,000 ng |
| T3 | 200,000,000,000,000 | 500 шт | 40%C 30%R 20%E 8%L 2%G | 1,200,000,000 ng |
| T4 | 1,000,000,000,000,000 | 1000 шт | 30%C 30%R 25%E 12%L 3%G | 2,500,000,000 ng |

**Колоды имеют лимитированную серию** — каждая колода это отдельная «серия» (Set 1, Set 2...). Когда колода распродана — банкноты этой серии больше не минтятся. Создаётся **искусственный дефицит**.

Психологический крючок:
  - «Set 1 почти распродан. Надо успеть.»
  - «У меня полный Set 1. Он больше не выпускается. Мои банкноты — антиквариат.»

### 2.4 Investor Token (автоматическая эмиссия для инвесторов)

Каждый раз при достижении казначейством нового tier, **инвесторы (аудиторы + first investor)** получают бесплатные токены:

### 4.1 Автоматический реинвест дивидендов

Когда банкнотхолдер получает дивиденды (ng):
  - Если баланс > 0, система предлагает: «Купить ещё 1 банкноту Common за X ng? Да / Нет / Не спрашивать»
  - По умолчанию — Да (opt-out, не opt-in)
  - Это превращает дивиденды в новые покупки => новый USDT => новые silver rounds => новые дивиденды

**Эффект:** Капитал никогда не покидает систему. Он просто циркулирует внутри.

### 4.3 Silver Spot Oracle (динамическая цена)

Вместо хардкода $75/oz — реальный API silver spot.

```go
type SilverOracle struct {
    spotPrice float64 // $/oz
    updatedAt time.Time
}

func (so *SilverOracle) refresh() {
    // Запрос к api.metals.live или аналогу
    price := fetchSilverSpot()
    so.spotPrice = price
    so.updatedAt = time.Now()
    
    // Если цена выросла >5% за сутки — триггер silver round
    // (чтобы захватить момент роста)
    if price > so.spotPrice * 1.05 {
        triggerEmergencySilverRound()
    }
}
```

**Эффект:** Рост цены серебра в реальном мире = автоматический профит для держателей банкнот. Это привязывает игру к реальному рынку.

### 4.4 Дефляционные механизмы

Чтобы ng не обесценивались:

| Механизм | Как работает |
|----------|-------------|
| **Сжигание банкнот** | Crafting: 5 → 1 (уничтожение 4) |
| **Аукционная комиссия** | 5% с каждой продажи → в treasury (часть сжигается) |
| **Treasury burn** | При «очень жирной» казне: 40% в burn |
| **Подписки** | 30% стоимости подписки сжигается |
| **Minting fee** | 1% при эмиссии franchise (см. FRANCHISE документ) |

**Эффект:** Чем активнее игра — тем больше сжигается. Supply уменьшается. Цена растёт.

## 6. ПОЧЕМУ ЭТО НЕ ОСТАНОВИТЬ (после достижения критической массы)

### 6.1 Сетевые эффекты (Network Effects)

Каждый новый пользователь:
  - Покупает банкноты → растёт казна → растут дивиденды → старым пользователям выгодно
  - Увеличивает liquidity на аукционах → легче торговать
  - Добавляет контент в чаты, радио, стримы

**Формула ценности:** `V = n * log(m)`, где n — пользователи, m — банкноты в обращении.
Чем больше людей — тем ценнее каждая банкнота. Чем ценнее банкноты — тем больше людей хотят их купить.

### 6.2 Lock-in эффекты

| Что lock-ит пользователя | Сила |
|------------------------|------|
| Статус (титулы, рейтинг) | Medium |
| Golden Royal (x4 dividends) | High |
| Collection completion | High |
| Investor tier | Very High |
| Social graph (чаты, друзья, роли) | Very High |
| Physical banknotes (PDF, signature) | Maximum |

### 6.3 Математическая необратимость

```
Silver Price (растёт) → USDT inflows (растут) → Treasury (растёт) 
→ Auto-mint новых колод → больше банкнот → больше аукционов 
→ больше комиссий → больше дивидендов → больше держателей 
→ больше спроса → больше USDT → ...

Любая остановка = потеря накопленного.
Любой выход = продажа банкнот (кому? другим игрокам, которые не выходят).
```

Система стремится к равновесию, где:
  - Цена банкноты определяется рынком
  - Дивиденды = функция от активности
  - Активность = функция от количества игроков
  - Количество игроков = функция от дивидендов

Это **самореферентная петля**. Она не требует внешнего управления. Требуется только seed-капитал (первые silver rounds) и люди.

## 10. ИТОГОВАЯ ФОРМУЛА

```
Успех = F(S, G, N, T), где:

S = Silver Standard (реальная ценность, не фантик)
G = Game Mechanics (коллекционирование, аукционы, крафт, статус)
N = Network Effects (каждый новый игрок повышает ценность для всех)
T = Treasury Flywheel (USDT → silver → dividends → demand → USDT)

Если S > 0 и G > 0 и N > 0:
    T → ∞ (самоподдерживающийся рост)
    Систему нельзя остановить, потому что:
      - У игроков есть накопленная ценность (банкноты, статус)
      - У игроков есть социальные связи (чаты, роли)
      - Рынок сам устанавливает цену банкнот
      - Казна растёт автоматически
      - Дефляция защищает от перегрева
```

Итог: **это не приложение, которое закрывается. Это экономический организм, который живёт, пока в нём есть хотя бы один игрок.**
