## 5. Текущая стоимость проекта (ранняя альфа, as-is)

Оценка различными методами:

| Метод | Стоимость | Обоснование |
|-------|-----------|-------------|
| **Стоимость пересоздания** (без ИИ) | **$600K** | 16 000 человеко-часов по рыночным ставкам |
| **Стоимость пересоздания** (с текущими ИИ-инструментами) | **$150K** | ~1 000 вызовов GPT-4o + контроль человека |
| **ICO-ready актив** | **$250K–$500K** | Уайтпейпер + токеномика + MVP + 3-язычная документация |
| **Crypto/MVP аналоги** (CoinList, DEX-продажи) | **$200K–$800K** | Работающий экономический движок + 4 бота + Docker + Tor |
| **IT InvestFund ранняя альфа** | **$150K–$350K** | Типичный диапазон pre-seed fintech с рабочим MVP |

**Справедливый диапазон: $200 000 – $400 000**

### Ключевые факторы стоимости

**Повышают ценность:**
- Полноценный экономический движок (9 441 строка) с серебряным обеспечением, POS, аукционами, подписками, дивидендами, арбитражем, крафтингом
- 4 Telegram-бота с данными в реальном времени, AI Steward, мониторинг
- Многоязычный уайтпейпер + ICO-концепция — готово для инвесторской презентации
- Запущено в продакшн на Tor hidden services с Docker-оркестрацией
- Нет уязвимостей внешних зависимостей (чистый Go, статический бинарник, без CGO)

**Понижают ценность:**
- Flutter-приложения не собираются (нет SDK на сервере)
- 4 контейнера нездоровы/перезапускаются
- Нет git-истории (репозиторий сброшен)
- Нет CI/CD-пайплайна
- Некоторые пакеты не покрыты тестами (channels, radio, webrtc)
- Нет юридического лица / инкорпорации
