# Saint Mary Liberty Island — White Paper (Русский)

## Первая в мире частная суверенная цифровая нация с обеспеченной серебром экономикой

**Версия:** 1.0 | **Дата:** Июнь 2026 | **Кодовое имя:** "The Isle" / "Остров"
**Контакты:** admin@stmaria.org | **Протокол:** SimpleX + Tor

---

## Краткое содержание

Saint Mary Liberty Island строит инфраструктуру для **суверенной цифровой нации** — частной, зашифрованной сети общения и экономики, где люди могут общаться, совершать транзакции и управлять собой без слежки, цензуры или посредников. В основе — **simplex-node**, один Go-бинарник, обеспечивающий весь стек: приватный обмен сообщениями (SimpleX/Tor), обеспеченную серебром цифровую валюту (Liquid Taler), управляемую ИИ экономическую политику (Steward), инструменты для мерчантов (POS) и мультичейн крипто-мосты (TRON/TON).

Мы не блокчейн-стартап. Мы — **платформа полной цифровой суверенности** — операционная система для нации без территории.

## 1. Проблема

### 1.1 Конфиденциальности больше нет
Каждое сообщение, каждая транзакция, каждое финансовое движение отслеживается, логируется и монетизируется. Сквозное шифрование атакуется по всему миру. «Пять глаз», «девять глаз», «четырнадцать глаз» — аппарат слежки растёт с каждым днём.

### 1.2 Деньги ненадёжны
- Фиатные валюты теряют 2-7% покупательной способности ежегодно
- CBDC угрожают программируемым контролем денег
- Криптовалюты волатильны, сложны и отслеживаемы
- Физическое серебро непрактично для цифровых платежей

### 1.3 Цифровых наций не существует
Ни один существующий проект не объединяет **частный обмен сообщениями + обеспеченный серебром стейблкоин + самокастоди + инструменты для мерчантов + ИИ-управление** в единую платформу. Пользователи вынуждены собирать 5-10 разных сервисов, каждый со своей моделью безопасности и рисками слежки.

## 3. Экономика Liquid Taler

### 3.1 Денежная политика

- **1 Liquid Taler (TLR)** = 31 103 480 000 ng (нанограмм) = 1 тройская унция серебра по споту
- **Обеспечение серебром:** 70% физического серебра в резерве
- **Премия за удобство:** 30% — ценность сети (скорость, приватность, удобство)
- **Максимальная комиссия:** 4.20% (казна берёт 2.28%, не больше)
- **Комиссия казны:** Ровно 228 BPS (2.28%) с каждой транзакции — без исключений

### 3.2 Модель эмиссии (70 oz → 100 TLR)

При запуске серебряного раунда:

| Адресат | % | Получатель |
|---------|---|-----------|
| Инвестор | 70.0% | Сторона, заплатившая USDT |
| Казна | 2.4% | Операционный бюджет ноды |
| Дивидендный пул | 14.1% | Держатели банкнот (по весу редкости) |
| Покупка серебра | 3.0% | Будущие закупки серебра |
| Аукционный пул | 4.5% | Ликвидность аукциона |
| Пул выкупа | 6.0% | Резерв выкупа банкнот |

### 3.3 Дефляционные механизмы

- **Сжигание казной:** 20-40% при толстых слоях казны
- **Сжигание подписок:** 30% дохода от подписок
- **Сжигание аукционов:** 5% аукционных сборов
- **Сжигание рекламы:** 20% покупок рекламных тегов

Эти дефляционные силы создают встроенное давление роста стоимости ng.
