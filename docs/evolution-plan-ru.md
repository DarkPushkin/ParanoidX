## 2. Целевые персоны пользователей

### Персона A: Профессионал, ценящий приватность (B2C)
- **Профиль:** Журналист, активист, крипто-трейдер, удаленный работник
- **Боль:** WhatsApp/Telegram недостаточно приватны
- **Готов платить:** $5-15/мес за приватные коммуникации + экономику
- **Размер:** ~500M по всему миру

### Персона B: Предприятие / DAO / Сообщество (B2B)
- **Профиль:** Управляющий DAO-казначейством, оператор сообщества
- **Боль:** Нужны суверенные коммуникации + казначейство + управление в одном
- **Готов платить:** $100-1000/мес за узел как сервис
- **Размер:** ~50K DAO + privacy-команд

### Персона C: Островитянин / Суверенная личность (B2C Premium)
- **Профиль:** Сторонник "цифровых наций", крипто-энтузиаст, ценит свободу
- **Боль:** Ни одна платформа не уважает истинный суверенитет
- **Готов платить:** $20-50/мес за полный стек
- **Размер:** ~5M по всему миру
